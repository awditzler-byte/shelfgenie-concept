# ShelfGenie website concept

A responsive editorial website concept for ShelfGenie, created for design review. It pairs approachable cabinet upgrades with a premium custom closet experience.

## View locally

Serve this folder with any static HTTP server and open index.html. No installation or build step is required.

## Publish with GitHub Pages

Publish the main branch from the repository root in Settings → Pages. The `.nojekyll` file keeps the site buildless. All asset paths are relative, so project-based GitHub Pages URLs work.

## Included experiences

- Responsive desktop and mobile layouts with local Outfit brand typography
- Real ShelfGenie photography from supplied marketing materials
- Room and solution dialogs
- Original interactive design studio with 8 rooms, 3 design levels, 40 finish samples and illustrative per-design pricing
- Filterable collection gallery
- Genuine pantry before-and-after photography
- Accessible FAQ disclosures and reduced-motion support
- Consultation preview with validation, focus handling and no data transmission
- Official ShelfGenie booking and local-service links for real inquiries

## Important

This is a website concept, not the live ShelfGenie site. The demo consultation form does not send, store or reserve anything. Real inquiries link to the official site. There is no analytics, tracking, customer data storage or production lead integration.

Photography, logos and brand content remain the property of ShelfGenie and their respective owners. Outfit is included under the SIL Open Font License in `assets/OFL-Outfit.txt`. Product availability, terms and services vary by location. All Design Studio prices are illustrative, not approved ShelfGenie pricing, and not a quote. The original studio was provided by the user; its pricing logic and disclaimers are preserved.

The internal `research/` directory is excluded from version control and deployment. Source PDFs and internal marketing playbooks are not part of the public website. `robots.txt` and the robots meta tag discourage indexing of this review concept.
